## მუშაობა და პასუხი

გარემოს გამართვა, სრული აპლიკაცია, deployment და SQL-ის გაშვება საჭირო არ არის. სავარჯიშოსთვის production წვდომა არ გჭირდება. რეალური კლიენტის კოდი, მონაცემები, PII ან credentials არ გამოიყენო.

AI დაშვებულია და ფასიანი ინსტრუმენტი საჭირო არაა. ყურადღება გაამახვილე გადაწყვეტილებების ახსნაზე, tradeoff-ებზე და იმაზე, როგორ შეამოწმებ შენს ვარაუდებს. AI რჩევის განხილვის მოთხოვნა იხილე დავალების მე-4 ნაწილში.

მე-2 ნაწილი დამოუკიდებელი day 60 სცენარია. მე-3 ნაწილი ცალკე ინციდენტია; მე-2 ნაწილის restore rehearsal-ის შედეგები მასზე არ ვრცელდება.

პასუხი მოამზადე ერთ დოკუმენტად. ვადა შენს გრაფიკზე მორგებით შეთანხმდება; გაცნობის შემდეგ მოგვწერე მოსახერხებელი დრო. მიუთითე რეალურად დახარჯული დრო და ის, რისი შესრულებაც ვერ მოასწარი.
